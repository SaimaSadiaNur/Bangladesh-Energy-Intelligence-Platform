It's an automated intelligence system that:

1. Scrapes energy news from major English newspapers.
2. Collects a handful of key market indicators (Brent, LNG, USD/BDT, etc.).
3. Cleans and structures the data automatically.
4. Uses Power Query and the Data Model.
5. Performs analysis with advanced DAX.
6. Presents insights in an executive dashboard.
7. Updates automatically through Power Automate Desktop.
