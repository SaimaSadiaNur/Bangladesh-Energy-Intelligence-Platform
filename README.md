# It's an automated intelligence system that:

1. Scrapes energy news from major English newspapers.
2. Cleans and structures the data automatically.
3. Uses Power Query and the Data Model.
4. Performs analysis with advanced DAX.
5. Presents insights in an executive dashboard.
6. Updates the dataset automatically through Python.

# Classification Engine

This dashboard uses a rule-based keyword classification system. As new entities, technologies, countries, and energy topics appear in the news, the keyword mapping tables are updated without changing the ETL process or dashboard logic.
